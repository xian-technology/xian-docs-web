# Authenticated Token Approvals

Use a signed `currency.approve(amount, to)` transaction to grant an allowance.
The spender then calls `currency.transfer_from(amount, to, main_account)`.
Use `currency.transfer(amount, to)` when no delegated allowance is needed.

The node verifies the sender against the current account registry. An enrolled
account requires its current hybrid active keys; the original Ed25519 key
cannot authorize an approval. See [Account Backups and Recovery](/concepts/hybrid-account-recovery).

Currency exposes no off-chain permit gateway. The XSC-0002 specification in
`xian-xips` is historical reference material, outside the current currency ABI.
See [XSC-0001](/smart-contracts/standards/xsc-0001) for the token interface.
